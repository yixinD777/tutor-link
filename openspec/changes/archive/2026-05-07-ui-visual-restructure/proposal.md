## Why

当前家教直连平台的 UI 是功能正确但视觉无感的 CRUD 界面：冷蓝色调(#4A90D9)、单列列表布局、扁平信息层级、零品牌性格。作为连接家长与大学生家教的 C 端产品，页面缺乏"发现感"和"信任感"，用户首次进入时无法产生情感共鸣。需要从冷蓝工具风格全面转向小红书式暖色视觉风格，让平台从"能用"变成"想用"。

## What Changes

- **BREAKING**: 全站主色从 `#4A90D9`(冷蓝) 切换为 `#FF6B6B→#FF8E53` 珊瑚暖色渐变系
- 首页从单列列表重构为渐变头部 + 双列瀑布流卡片网格布局
- 登录页从灰底表单重构为全屏渐变品牌页
- 家教详情页顶部增加渐变 hero 区域，信息层级重新划分
- 家教列表页从单列卡片改为双列网格 + 吸顶筛选胶囊
- 个人中心增加渐变头部背景和数据面板
- 聊天气泡样式更圆润，输入栏更像微信风格
- 订单详情页状态栏渐变色适配新主色
- 所有 Tl* 组件配色跟随新设计系统更新

## Capabilities

### New Capabilities
- `warm-color-system`: 珊瑚暖色系设计 token 体系 — 新主色、渐变、语义色、暗色适配的全套 SCSS 变量替换
- `waterfall-grid-layout`: 双列瀑布流/网格卡片布局组件 — 首页推荐家教和列表页共用的卡片网格
- `gradient-hero-section`: 渐变头部区域 — 首页搜索区、登录页、家教详情页、个人中心顶部的渐变背景模块

## Impact

- **SCSS 设计系统**: `uni.scss` 中所有 `$color-primary*` 变量和语义色需全面替换
- **19 个 Tl* 组件**: 按钮主色、卡片阴影、状态徽章配色、标签色等全部需跟随新 token
- **19 个页面**: 模板结构(layout)、样式(scoped SCSS)均需改动，尤其首页需大幅重构模板
- **无后端影响**: 纯前端视觉层变更，不涉及 API/数据结构改动
- **无路由变更**: 页面路径和导航逻辑不变
